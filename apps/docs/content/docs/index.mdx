## Build from the contract

Same factory as Vortex Payments. Never handwrite clients.

- Spec: `docs/openapi/password-manager.openapi.json`
- Base URL: `https://veil.nyc`
- Regenerate SDKs: `pnpm run sdk:generate`
- Run this site: `pnpm run docs:dev`
